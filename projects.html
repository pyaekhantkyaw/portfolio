01 / END-TO-END POWER BI

Olist E-commerce Sales & Logistics

A portfolio simulation of an e-commerce BI engagement using the public Brazilian Olist dataset (2016–2018). The goal was to support revenue analysis, operational monitoring and seller-level access to insights.

View Olist on GitHub ↗All project case studies ↑

Data & modeling

  • Nine relational CSV sources cleaned and typed in Power Query.
  • Multi-fact dimensional model with explicit business grains and date dimensions.
  • Handled missing values and duplicate records while retaining meaningful business states.
  • Built 20+ DAX measures for revenue, fulfillment and customer sentiment.

Delivery & governance

  • Six report pages, with drill-through and tooltips for deeper investigation.
  • Power BI Service workspace, gateway and scheduled refresh; incremental refresh preparation.
  • Seller-level row-level security, KPI alerts and a restricted-access Power BI App.
  • Executive dashboard with mobile layout and published report documentation.

Business questions

  • Which categories and regions generate revenue?
  • Where are delivery delays concentrated?
  • How does delivery performance relate to customer ratings?
  • How can sellers view only their own performance?

Scope & next steps

This is an independent project, not an employer deployment. The dataset uses static CSV files; a production iteration could use a database or warehouse, more granular security and deployment automation.

02 / SQL → PYTHON → POWER BI

SaleOps Automotive Sales Analytics

An independent analytics workflow for automotive transactions, connecting database querying, exploratory analysis and business reporting to investigate sales and operating performance.

View SaleOps on GitHub ↗All project case studies ↑

01. SQL business analysis

Used SQLite queries with CTEs, window and ranking functions to compare product lines, revenue, customer segments and warehouse performance.

02. Python exploration

Used pandas and NumPy for data manipulation, with Matplotlib, Seaborn and Plotly for trends, distributions, rolling averages and comparative analysis.

03. Power BI reporting

Built an executive report for net revenue, orders, payment patterns, product and warehouse comparisons, and customer insights.

What this demonstrates

Ability to translate business questions into analytical queries, investigate patterns with code, and present findings through a visual reporting layer. The notebooks and PBIX provide the evidence.
